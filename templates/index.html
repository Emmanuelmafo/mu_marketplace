Install MU Marketplace

Add MU Marketplace to your device for quick access, just like an app.

Android (Chrome): Open the browser menu (⋮), then choose Install app or Add to Home screen.

iPhone/iPad (Safari): Tap Share, then choose Add to Home Screen.

Computer (Chrome/Edge): Use the install icon in the address bar, or choose Install MU Marketplace from the browser menu.
